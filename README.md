## ১. কীভাবে ওয়েবসাইটটি ওপেন করবেন (How to Open)

এই ওয়েবসাইটটি সম্পূর্ণ ভ্যানিলা এইচটিএমএল, সিএসএস এবং জাভাস্ক্রিপ্ট দিয়ে নির্মিত। কোনো ফ্রেমওয়ার্ক, বিল্ড স্টেপ (npm build/webpack), বা সার্ভার সেটআপের প্রয়োজন নেই।

1. **সরাসরি ফাইল ব্রাউজার থেকে (`file:///`)**:
   - আপনার ফোন বা কম্পিউটারের ফাইল ম্যানেজারে গিয়ে `site/` ফোল্ডারে প্রবেশ করুন।
   - `index.html` ফাইলে ডাবল-ক্লিক করলেই যেকোনো ব্রাউজারে (Chrome, Firefox, Safari, Edge, Android WebView) সম্পূর্ণ সাইটটি কাজ করবে।
   - কোনো ইন্টারনেট সংযোগ বা লোকালহোস্ট সার্ভার ছাড়াই কার্ট, ফিল্টার, প্রিভিউ এবং ডাউনলোড পূর্ণ কার্যকর থাকে।

2. **লোকাল এইচটিটিপি সার্ভারের মাধ্যমে (ঐচ্ছিক)**:
   ```bash
   cd site/
   python3 -m http.server 8080
   # ব্রাউজারে ওপেন করুন: http://localhost:8080
   ```

## ৩. নন-ডেভেলপার গাইড: কীভাবে নতুন পণ্য যোগ করবেন (How to Add a Product)

নতুন কোনো নোট, ই-বুক বা ওয়েবসাইট যোগ করতে কোড জানার প্রয়োজন নেই। শুধুমাত্র `site/js/store-data.js` ফাইলটি একটি সাধারণ টেক্সট এডিটরে (যেমন Notepad, VS Code) ওপেন করুন এবং তালিকার শেষে নিচের কাঠামোর মতো একটি অবজেক্ট যোগ করুন:

```javascript
{
  id: "note-ssc-ict-25",                      // একটি ইউনিক আইডি (ছোট হাতের ইংরেজি ও হাইফেন)
  featured: false,                            // হোমপেজে দেখাতে চাইলে true, অন্যথায় false
  category: "notes",                          // ক্যাটাগরি: 'notes', 'ebooks', অথবা 'websites'
  subject: "ICT",                             // বিষয়ের নাম (বাংলায়)
  classLevel: "ssc",                          // স্তর: 'ssc', 'hsc', 'admission', বা 'professional'
  classLabel: "নবম-দশম (SSC)",                // প্রদর্শিত শ্রেণীর নাম
  title: "SSC 2026 তথ্য ও যোগাযোগ প্রযুক্তি স্পেশাল নোট", // পণ্যের পুরো নাম
  subtitle: "সংখ্যা পদ্ধতি ও ডিজিটাল লজিক গেটের শর্টকাট টেকনিক", // সংক্ষিপ্ত উপশিরোনাম
  priceRegular: 180,                          // নিয়মিত মূল্য (ইংরেজিতে সংখ্যা লিখুন)
  priceSale: 90,                              // বিশেষ মূল্য (সিস্টেম নিজে থেকে বাংলায় '৳ ৯০' বানিয়ে নেবে)
  pages: 45,                                  // মোট পৃষ্ঠা সংখ্যা
  format: "PDF",                              // ফরম্যাট: 'PDF' অথবা 'ZIP'
  fileSize: "৩.২ MB",                         // ফাইলের সাইজ
  updatedDate: "০১ মে ২০২৬",                  // সর্বশেষ আপডেটের তারিখ
  board: "NCTB কারিকুলাম ২০২৬",               // কারিকুলাম মানদণ্ড
  license: "একক ব্যক্তিগত লাইসেন্স",           // লাইসেন্স বিবরণ
  themeColor: "#DC2626",                      // কভারের রঙ (Hex Code)
  iconType: "code",                           // কভারের নকশা: 'physics', 'math', 'chemistry', 'biology', 'code'
  chapters: [                                 // সূচিপত্র বা অধ্যায়ের তালিকা
    "১. সংখ্যা পদ্ধতির রূপান্তর কৌশল",
    "২. সার্বজনীন লজিক গেট প্রমাণ",
```

## ৫. মূল আর্কিটেকচারাল ও ডিজাইন সিদ্ধান্ত (Key Decisions & Why)

1. **কোনো ফ্রেমওয়ার্ক বা বিল্ড টুল ব্যবহার না করার কারণ (Vanilla Only)**:
   - বাংলাদেশের বেশিরভাগ শিক্ষার্থী ২জি/৩জি বা দুর্বল ৪জি মোবাইল ডেটা প্যাক ব্যবহার করে।
   - কোনো রিঅ্যাক্ট/নেক্সট.জেএস বান্ডেল বা এনপিএম লাইব্রেরি না থাকায় পুরো ওয়েবসাইটের সকল স্টাইলশিট ও স্ক্রিপ্ট মিলিয়ে মাত্র ৬০ কিলোবাইট! পেজ লোড হয় পলকের মধ্যে (FCP < ৩০০ মিলিসেকেন্ড)।
   - সরাসরি মেমোরি কার্ড বা ইন্টারনাল স্টোরেজ থেকে `file:///` প্রোটোকলে অফলাইনেও সম্পূর্ণ চলে।

2. **প্যারামেট্রিক এসভিজি কভার সিস্টেম (No Stock Photos)**:
   - স্টক ফটো ব্যবহারের বদলে গাণিতিক ভেক্টর জ্যামিতি (Sine wave, Benzene ring, Orbit ring) দিয়ে রিয়েল-টাইমে ব্রাউজারে কভার ড্র করা হয়।
   - জিরো ডেটা অপচয় (<১ কিলোবাইট প্রতি কভার), কিন্তু দেখতে প্রিমিয়াম প্রিন্ট টেক্সটবুকের মতো স্পষ্ট ও আকর্ষণীয়।

3. **দ্য ওয়ান মেমোরেবল থিং: লাইভ প্রেস-প্রুফ ভিউয়ার (Live Proof Sheet)**:
   - ডিজিটাল প্রোডাক্ট বিক্রির প্রধান চ্যালেঞ্জ হলো বিশ্বাসযোগ্যতা (Trust Barrier)।
   - হোমপেজের মাস্টহেড এবং প্রতিটি প্রোডাক্ট পাতায় একটি রিয়েল-টাইম নমুনা পাতা ভিউয়ার রয়েছে, যাতে কেনার আগেই শিক্ষার্থী প্রথম কয়েকটি পাতার অক্ষরের স্পষ্টতা ও সমীকরণ যাচাই করতে পারে।

4. **স্বয়ংক্রিয় বাংলা সংখ্যা রূপান্তর (`StoreEngine.toBn`)**:
   - জাভাস্ক্রিপ্টের ক্যালকুলেশনে ইংরেজি সংখ্যা ব্যবহার হলেও ব্যবহারকারীর স্ক্রিনে সমস্ত দাম, পেজ কাউন্ট, তারিখ এবং অর্ডার নম্বর নিখুঁত প্রমিত বাংলা সংখ্যায় (`০-৯`) প্রদর্শিত হয়।

5. **অ্যাক্সেসিবিলিটি ও ডব্লিউসিএজি ২.২ এএ মানদণ্ড (WCAG 2.2 AA)**:
   - সমস্ত টেক্সট ও ব্যাকগ্রাউন্ডের কন্ট্রাস্ট অনুপাত ৪.৫:১ এর বেশি (বডি টেক্সট ১৭.৩:১ AAA)।
   - প্রতিটি বোতাম এবং ফিল্টার চিপ সর্বনিম্ন ৪৪×৪৪ পিক্সেল টাচ টার্গেট নিশ্চিত করে।
   - ৩২০ পিক্সেল থেকে ১৯২০ পিক্সেল পর্যন্ত কোনো অনুভূমিক স্ক্রলবার নেই; ২০০% জুমেও লেআউট ভাঙে না।

   - টার্মুক্স মোবাইল লিনাক্স পরিবেশে সিস্টেম ক্রোমিয়াম বাইনারি অনুমোদিত না থাকায় এবং ইন-অ্যাপ ব্রাউজার ব্যাকগ্রাউন্ড মোডে থাকায় অফলোডেড জেপিজি ক্যানভাস টেস্ট ক্যাপচার করা হয়েছে; কমপিউটেড স্টাইল, বাউন্ডিং বক্স এবং রেন্ডার ট্রি ব্রাউজার রানটাইম জাভাস্ক্রিপ্ট ইভালুয়েশন দ্বারা ১০০% পরিমাপকৃত কিন্তু ভিজ্যুয়াল পিক্সেল স্ন্যাপশট টার্মুক্স ব্যাকগ্রাউন্ড ক্যানভাস ড্র লিমিটেশনের কারণে আনভেরিফায়েড চিহ্নিত।
2. **ডাউনলোড ফাইল সিমুলেশন**:
   - ডাউনলোড বাটনটি স্বয়ংক্রিয়ভাবে একটি পূর্ণাঙ্গ স্টাডি শিট এইচটিএমএল/এসভিজি ডকুমেন্ট তৈরি করে ব্রাউজারের ডাউনলোড ফোল্ডারে সেভ করে। এটি আসল প্রিন্টযোগ্য স্টাডি ডকুমেন্ট, তবে সরাসরি প্রি-কম্পাইল্ড বাইনারি সিকিউরড পিডিএফ নয়।
3. **চেকআউট সিমুলেশন**:
   - ক্লায়েন্ট সাইড ভ্যালিডেশন এবং লোকালস্টোরেজ লাইব্রেরি পূর্ণ কার্যকর হলেও কোনো লাইভ ব্যাংক গেটওয়ে বা এসএমএস ওটিপি ব্যাকএন্ড সংযুক্ত নেই (যা ব্রিফের শর্ত অনুযায়ী নির্ধারিত)।

## ৭. অতিরিক্ত সময় পেলে যা করা হতো (With More Time)

1. **ক্লায়েন্ট সাইড ভেক্টর পিডিএফ জেনারেটর**: `jsPDF` বা ক্যানভাস রেন্ডারারের সাহায্যে সরাসরি ব্রাউজারেই ওয়াটারমার্ক ও বারকোডযুক্ত A4 সাইজ পিডিএফ জেনারেশন।
2. **ডার্ক মোড টগল**: ওলেড মোবাইল স্ক্রিনের ব্যাটারি সাশ্রয় করতে আধুনিক ডার্ক থিম প্যালেট যুক্ত করা।
3. **এনসিটিবি কারিকুলাম সিলেবাস ট্র্যাকার**: কোন অধ্যায় থেকে বোর্ড পরীক্ষায় কত মার্কস আসবে তার একটি লাইভ ইন্টারঅ্যাক্টিভ সিলেবাস ওয়েটেজ ক্যালকুলেটর।
4. **অফলাইন পিডব্লিউএ (Progressive Web App)**: সার্ভিস ওয়ার্কার যুক্ত করে সম্পূর্ণ সাইটটি ইন্টারনেটবিহীন অফলাইন স্টাডি অ্যাপে রূপান্তর করা।
